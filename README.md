#Console application which reads file *Eugene_Onegin.txt* sorts, and prints to file *output.txt*

Onegin is a program, which reads input file, sorts it by alphabet from start and print it, then sorts it by alphabet from end and print it, then prints original file.

## Instalation

1. Clone repository: 
  enter in command line: git clone https://github.com/Kunanta0/Onegin.git
2. Open **c** compilator:
  use **path** in command line to the folder with compilator
3. You can open it from IDE too (instead of points 1 - 2).

## Using

1. Open project in command line:
  enter in command line: "cd>folder with project"
2. Compile project in command line:
  enter "g++ main.cpp -o <.exe file to open, auto - a.exe>"
3. Run project:
  enter "<path to .exe file>"
4. You can just run project in IDE (instead 1-3)

## Project structure

-  'main.c': Source file
-  'Sorters.h': File with input sorters
-  'comparators.h': File with comparators
-  'maths.h': File with maths functions
-  'MyString.h': File with my string functions
-  'Eugene_Onegin.txt' - input file
-  'output.txt' - output file
